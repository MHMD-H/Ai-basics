🧠 أولًا: ليه نستخدمهم أصلاً؟

كلهم بيحلوا مشكلة واحدة:

عندك data high-dimensional (10, 100, 1000 feature)
عايز:

تقلل الأبعاد (dimensionality reduction)
تصور الداتا (visualization)
تقلل noise
تحسن أداء الموديل
🔷 1) PCA (Principal Component Analysis)
🎯 الغرض:
تقليل الأبعاد مع الحفاظ على أكبر قدر من الـ variance
⚙️ بيشتغل إزاي؟

الفكرة الأساسية:

بيلاقي أفضل directions (محاور) تمشي عليها الداتا

📌 رياضيًا:
z=XW

X = الداتا
W = الاتجاهات (components)
z = الداتا بعد التحويل
💡 التفسير:
بيحسب covariance matrix
يطلع eigenvectors (الاتجاهات)
يرتبهم حسب eigenvalues (الأهمية)
ياخد أهم k directions
🔥 مميزاته:
سريع جدًا ⚡
deterministic (نفس النتيجة كل مرة)
مناسب للـ preprocessing
❌ عيوبه:
linear فقط
مش بيحافظ على structure المعقد
🧠 تستخدمه إمتى؟

✔ قبل ML model
✔ تقليل noise
✔ لما البيانات linear
✔ feature engineering

🔴 2) t-SNE (t-Distributed Stochastic Neighbor Embedding)
🎯 الغرض:
visualization قوي جدًا (2D / 3D)
⚙️ بيشتغل إزاي؟

الفكرة:

يحافظ على "الجيران" (local structure)

📌 بيحول المسافات → probabilities
وبعدين يحاول يخليها شبه بعض في low-dim

💡 الفكرة ببساطة:
لو نقطتين قريبين → يفضلوا قريبين
لو بعيدين → مش مهم قوي
🔥 مميزاته:
بيطلع clusters واضحة جدًا 🔥
ممتاز في visualization
❌ عيوبه:
بطيء 😅
مش stable (كل مرة نتيجة مختلفة)
مش مناسب للتنبؤ
global structure بيضيع
🧠 تستخدمه إمتى؟

✔ visualization فقط
✔ explore clusters
✔ data معقدة nonlinear

🟢 3) UMAP (Uniform Manifold Approximation and Projection)
🎯 الغرض:
تقليل أبعاد + visualization
(بديل حديث لـ t-SNE)
⚙️ بيشتغل إزاي؟

الفكرة:

الداتا عايشة على manifold، نحافظ عليه

يبني graph بين النقاط (neighbors)
يحافظ على local + global structure
🔥 مميزاته:
أسرع من t-SNE ⚡
يحافظ على global + local structure
scalable
ينفع training + prediction
❌ عيوبه:
محتاج tuning parameters
أحيانًا أصعب في الفهم
🧠 تستخدمه إمتى؟

✔ visualization
✔ preprocessing قبل ML
✔ datasets كبيرة
✔ لما عايز توازن بين local و global

⚔️ مقارنة سريعة
الخاصية	PCA	t-SNE	UMAP
نوع	Linear	Nonlinear	Nonlinear
السرعة	سريع جدًا ⚡	بطيء 😅	سريع ⚡
يحافظ على	Global	Local	Local + Global
مناسب لـ ML	✔	❌	✔
Visualization	متوسط	ممتاز 🔥	ممتاز 🔥
🧠 الخلاصة الذكية (احفظ دي)
🔵 PCA = تنضيف وتقليل أبعاد سريع
🔴 t-SNE = رسم clusters بشكل جميل
🟢 UMAP = أفضل توازن + عملي
🚀 تستخدمهم إزاي في real project؟
Data → Scaling → PCA (optional)
          ↓
    Visualization:
        → t-SNE أو UMAP
          ↓
    Modeling:
        → PCA أو UMAP
